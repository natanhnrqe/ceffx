CONTENTS
--------

bin         Contains the ceffx_app whose contents include Java archives and
            native library files.

docs        Contains documentation for the org.cef package.

tests       Contains the MainFrame sample application.

USAGE
-----

1. Install a 64-bit version of the Oracle Java 7 runtime.
2. Launch ceffx_app to run the MainFrame sample application.
3. Optionally recompile the sample application and update ceffx-tests.jar
   in the ceffx_app bundle by running the compile.sh script.

Please visit the CEFFX Website for additional usage information.

https://github.com/chromiumembedded/java-cef
